# Badge Art Direction

## Visual system

The 100 NovaMath Lab badges use a shared premium 3D enamel-pin style with bold silhouettes that remain readable at small sizes. The recurring visual themes are friendly dinosaurs, generic exotic sports cars, science exploration, colorful interlocking construction bricks, and mathematics.

The art is aimed at an enthusiastic middle-school learner: energetic and collectible, but not preschool-like. Badge images contain no text because the app provides localized names, descriptions, progress, and accessible labels.

## Tier language

- **Starter:** warm copper-orange rim with teal accents
- **Intermediate:** cool silver rim with cobalt, teal, and violet accents
- **Advanced:** dark platinum rim with gold filigree, amethyst, and cyan gems

All badges use deep navy interiors, polished enamel, readable central subjects, and transparent outer backgrounds.

## Final generation prompt set

All four images used the `stylized-concept` use case and requested a square transparent 5×5 game UI badge atlas with one centered circular medallion per cell, equal scale, generous gutters, and no overlap. Shared constraints were: exactly 25 badges per sheet; consistent premium 3D enamel-pin styling; no words, letters, numerals, logos, trademarks, brand-specific car shapes, watermarks, scary dinosaurs, weapons, or babyish presentation.
